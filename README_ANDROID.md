# দলিল ফিগার (Dalil Figure) - Android APK ও রিলিজ সিস্টেম (Kotlin)

এই প্রজেক্টটি Kotlin এবং Jetpack Compose ভাষায় Android অ্যাপ হিসেবে প্রস্তুত করা হয়েছে।

---

## 🌟 আপনার ৪টি বিশেষ সুবিধার বিবরণ:

### ১. সেইম সিগনেচার (Same Signature Keystore):
- প্রজেক্টের রুট ফোল্ডারে `android/release.keystore` সংরক্ষিত রয়েছে।
- প্রতিটি বিল্ড (Debug এবং Release) স্বয়ংক্রিয়ভাবে এই একই কি-স্টোর দিয়ে সাইন করা হয়।
- এর ফলে পূর্বের অ্যাপটি আন-ইনস্টল না করেই নতুন আপডেটগুলো সরাসরি ওপর দিয়ে ইনস্টল করা যাবে (কোনো Signature Mismatch বা App Not Installed এরর আসবে না)।

### ২. স্বয়ংক্রিয় ভার্সন বৃদ্ধি (Automatic Version Increment):
- আপনাকে কোডের ভেতরে বারবার `versionCode` বা `versionName` পরিবর্তন করতে হবে না।
- GitHub-এ প্রতিবার কোড পুশ করার সাথে সাথে GitHub-এর রান নাম্বারের ভিত্তিতে ভার্সন স্বয়ংক্রিয়ভাবে বৃদ্ধি পাবে:
  - ১ম পুশ: Version Code: `1`, Version Name: `1.0.1`
  - ২য় পুশ: Version Code: `2`, Version Name: `1.0.2`
  - ৩য় পুশ: Version Code: `3`, Version Name: `1.0.3` (ইত্যাদি)

### ৩. পুশ করার সাথে সাথে GitHub Releases-এ APK প্রকাশ:
- কোড `main` বা `master` ব্রাঞ্চে পুশ করার সাথে সাথেই GitHub Actions ব্যাকগ্রাউন্ডে APK তৈরি করবে।
- স্বয়ংক্রিয়ভাবে একটি নতুন ট্যাগ (যেমন: `v1.0.1`) তৈরি হবে।
- আপনার রিপোজিটরির **"Releases"** অপশনে স্বয়ংক্রিয়ভাবে রিলিজ নোটসহ `.apk` ফাইল আপলোড হয়ে যাবে।

### ৪. অ্যাপের ভেতর অটোমেটিক আপডেট নোটিফিকেশন ও ইন-অ্যাপ আপডেট:
- অ্যাপটি ওপেন করার সাথে সাথেই ব্যাকগ্রাউন্ডে GitHub Releases API চেক করবে।
- নতুন কোনো সংস্করণ রিলিজ হয়ে থাকলে অ্যাপের স্ক্রিনে সুন্দর পপ-আপ নোটিফিকেশন আসবে:
  - নতুন কী কী ফিচার বা পরিবর্তন এসেছে তার বিবরণ দেখাবে।
  - **"এখনই আপডেট করুন"** বাটনে চাপ দিলে অ্যাপের ভেতর থেকেই স্বয়ংক্রিয়ভাবে নতুন APK ডাউনলোড হবে (প্রগ্রেস বারসহ)।
  - ডাউনলোড শেষ হলে সরাসরি অ্যান্ড্রয়েডের প্যাকেজ ইনস্টলার ওপেন হয়ে যাবে এবং ১-ক্লিকেই অ্যাপ আপডেট হয়ে যাবে।
- এছাড়া অ্যাপের ওপরের বারে থাকা আপডেট আইকন চাপ দিয়ে ব্যবহারকারী যেকোনো সময় ম্যানুয়ালি আপডেট চেক করতে পারবেন।

আপনার কোড GitHub রিপোজিটরিতে পুশ করুন:
```bash
git add .
git commit -m "Configure auto releases, persistent signing keystore and in-app updates"
git push origin main
```
পুশ করার ২-৩ মিনিটের মধ্যে GitHub-এর **Releases** সেকশনে আপনার নতুন APK ফাইলটি তৈরি হয়ে যাবে!
